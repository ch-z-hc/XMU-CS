# XMU-CS

厦门大学课表查询工具，生成可在电脑和手机上查看的课表网页。

![课表页面，模拟数据](docs/schedule-demo.png)

## 功能

- 自动定位本周，支持切换周次。
- 显示下一节尚未结束的课，包含正在上的课，结束后自动切换，支持跨天、跨周。
- 周视图展示周一至周五，今日视图包含周末课程。
- 点击课程查看教师、教室、班级、上课时间和周次。
- 手机端支持单列今日视图。
- 课表保存在生成的页面中，查看时无需重新登录教务系统。

周次按厦大校历从周日开始计算。课表有调整时需重新运行程序更新。
